# Coverage and evidence index

The [operation matrix](OPERATIONS.csv) enumerates the 20 addressed register operations per SKU. The codec stages check the wire envelope. The measurement and setting stages implement the typed operations. The CLI, example and runner stages prove the same paths through the shared dispatcher and both full applications. Use the captured manuals for numerical bounds, frame bytes and units. The three independent bench stages record physical observations by model, register, address profile and setup. [Register inventory](../reference/protocol/registers.csv) · [Measurement and configuration](../reference/measurement-and-configuration.md) · [Wire timing](../reference/protocol/Modbus_RTU_notes.md)

| `0x0100` | R | `read processed` | `MeasurementKind::ProcessedDistance`, mm. A read starts ranging. 190–750 ms, with 300 ms as the Chinese SEN0592 lower figure. A delayed reply after abandonment cannot refresh another kind. |

| `0x0209` | RW | `config read uart-unit`, `config set uart-unit` | `Setting::UartUnit`, mm/us map to 0/1. Applies to automatic/controlled UART output. Factory setting unspecified. Reject 5 on SEN0591. Keep its 3 m rating separate from nominal level 4 and qualify the four per-level response times. |

`config read` also accepts the numeric register. `readreg` covers each of the twelve documented words with the same decoder and register side effects. `watch` and `latest` apply to all four measurement kinds with bounded live sampling and passive cache access respectively. Reject FC06 at each measurement register. Fast read-only probes stay useful for bring-up. Both full console examples expose the complete table.

Use the separate `profile dfrobot-isolated` path for extended endpoints. `broadcast set <key> <value> [confirm]` sends a checked FC06 to 0xFF explicitly on an isolated fixture, for each of the eight configuration keys. This destination has no documented reply or effect guarantee. Verify the chosen setting with a separate addressed read when a known endpoint is available. Standard shared-bus operations use 1..247. The source does not establish FC03 broadcast, a mode-selection register, automatic target identification or an assigned endpoint at 0 or 255.

## Requirements across the stages

The additional `readregs <start> <count>` diagnostic exercises the FC03 quantity field on a bounded contiguous span. The read codec, shared owner, live CLI and runner stages cover expected count, full raw words, exceptions, RX capacity and gap rejection. The measurement bench can record acceptance on each SKU. A three-word read of `0x0100` does not establish simultaneous sampling. Keep this separate from the twenty single-register operations and their sample counters.
