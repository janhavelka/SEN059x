# Coverage and evidence index

Use the captured manuals for numerical bounds, packet bytes and units. This index assigns the check that could otherwise be missed. Every row applies to both explicitly selected SKUs unless stated. Stage 03 checks the wire envelope. Stage 09 carries the surfaces below into shared help and diagnostics. Stage 14 records physical results by model, register and setup. [Register CSV](../reference/protocol/registers.csv) · [Measurement and configuration](../reference/measurement-and-configuration.md) · [RTU timing and vectors](../reference/protocol/Modbus_RTU_notes.md)

| Address | Contract for the portable core | Required observation or negative case |
| --- | --- | --- |
| `0x0100` | Stage 04. Processed distance in mm. Reading starts ranging. The general window is 190–750 ms, with 300 ms as the Chinese SEN0592 lower figure. | `read processed` updates only this reading. Stage 07 allows the upper estimate plus transport overhead. Test a delayed response arriving after abandonment. |
| `0x0101` | Stage 04. Real-time distance in mm, one ranging cycle per read, 15–140 ms. | `read realtime` uses the published frame. Repeating a read initiates a new measurement. Keep the processed sample's generation unchanged. |
| `0x0102` | Stage 04. Temperature reported in 0.1 °C units with 0.5 °C resolution. Timing 5–140 ms, with 40 ms as the Chinese SEN0592 lower figure. | `read temperature` returns the published positive example. Preserve the raw word and uncertain encoding for a possible subzero value. Sampling instant is unspecified. |
| `0x010A` | Stage 04. Echo time in µs. Reading starts a cycle. Same published timing alternatives as temperature. | `read echo` preserves µs. An explicitly approximate mm estimate uses µs / 5.75. Missing-echo encoding is open. Never combine separate readings into a simultaneous sample. |
| `0x0200` | Stage 05. Device address, factory 1. The manual allows 1–254. The supported unicast API and owner admit 1–247. | `setaddr` preview and isolated confirmation. Check the old-address echo and perform same-register readback at the proposed address. Reject 0, 248–255 before TX, including vendor broadcast 255 and standard broadcast 0. |
| `0x0201` | Stage 05. Immediate baud setting. Codes 2–9 mean 4800, 9600, 14400, 19200, 38400, 57600, 76800, 115200. Factory code 9 at 8N1. | `readbaud` and `setbaud` separate host and device state. ACK baud is unspecified. Verify at new baud, record loss/mismatch and whether host cleanup succeeded. Stage 08 rejects unsupported product rates before TX. |
| `0x0205` | Stage 05. Switch-only polarity 0/1. Below threshold, 0 selects low and 1 selects high (default). Equality unspecified. | Allow explicit register observation, label conditional. Four-wire RS485 pinout has no separate switch output. Keep this outside routine commissioning writes. |
| `0x0206` | Stage 05. Switch-only threshold 30–3000 mm on SEN0591 and 30–5000 mm on SEN0592. No factory threshold specified. | Check boundaries per SKU, including SEN0591's distinct 20 mm rated measurement minimum. Read surface only in the bench console. |
| `0x0208` | Stage 05. Angle levels 1–4, default 4. SEN0591 uses one angle table. SEN0592 has single and dual horizontal/vertical values. | `config set angle` distinguishes the model and axes, validates limits and requires observed readback. Keep the storefront vs per-level discrepancy visible. |
| `0x0209` | Stage 05. Automatic/controlled UART units, 0 mm or 1 µs. No factory setting specified. | Explicit read/inspect with a mode label. No documented RS485 mode selector. Changing or observing this register cannot change the unit of an RS485 measurement. |
| `0x021A` | Stage 05. Power-supply noise suppression levels 1–5, default 1. The manual describes effects on detection angle without a numerical correction. | `config set noise` validates range and reports readback. Publish all five supply examples with their source. |
| `0x021F` | Stage 05. Extended range levels 1–4 for SEN0591 (default 4), 1–5 for SEN0592 (default 5). Approximate distances 50/150/250/350[/500] cm. | `config set range` rejects level 5 for SEN0591. Its nominal level 4 exceeds the 3 m product rating. Exercise all four SEN0591 per-level timing rows alongside the wider general response windows. |

## Requirements across the stages

| Subject | Stages and evidence |
| --- | --- |
| Manufacturer and variant | 01/04/14. Match SKU label to supply, startup, rated limits, target geometry and source language. Use a reference target and retain raw data even when semantic validity is uncertain. [Hardware guide](../reference/hardware.md) |
| Public surface and lifetime | 02/06/08. Compile the headers alone and from the umbrella, check namespace, type/field names, owner of buffers, stable message lifetime, typed error detail, passive observers and explicit clock origin. [Conventions](CONVENTIONS.md) |
| RTU | 03/07. Exercise all six vendor transactions. Check endian order, low CRC byte first, exact 8-byte requests, 7-byte one-word reads, 8-byte writes, 5-byte exceptions, no trailing data and no prefix acceptance. Cover wire silence on both sides of 19200 baud, TX drain, turnaround and late untagged FC03 replies. [Frame notes](../reference/protocol/Modbus_RTU_notes.md) |
| Commissioning evidence | 05/07/09/12/14. Verify desired, sent, observed and trusted settings. Hold address/baud changes to an isolated unit. A timeout after TX, partial echo, local echo or reset needs an uncertain outcome. Track recovery and persistence separately. |
| Health and data age | 04/06/08/09. Track the last valid sample independently for each binding and measurement kind. A valid addressed exception can establish communication and still fail the operation. Client polls consume no UART traffic. Verify disabled, offline and recovering cases. |
| Consumer and scheduling | 07/08/14. Verify mixed traffic, one owner per UART, no overlapping transaction, waits that yield the bus, bounded deadlines, wraparound, retained terminal result, cancellation, stale replies and rebinding. Acoustically overlapping heads are a separate installation test. |
| CLI and examples | 09/10/11. One grouped help/dispatcher, readable units/status, passive and live paths, safe commissioning previews, per-command deadlines and bounded output. Compile and run fixture transcripts through both compositions. [CLI contract](CLI_CONTRACT.md) |
| Runner and qualification | 12/14. Capture boot/session/request/operation identity, replay fault transcripts and separate hardware data from host fakes. Use the direct USB–RS485 probe independently. |
| Packaging and closeout | 13/15. Native C++17, Arduino ESP32-S3, native ESP-IDF example and an independent consumer of the exported archive each exercise their real entry point. Report software results and physical gaps by SKU. [Verification](VERIFICATION.md) |
